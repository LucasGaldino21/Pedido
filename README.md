# Uma pergunta para Gabi 💙

Site interativo de pedido de namoro, feito em Next.js + React + TypeScript.

## Rodar localmente

1. Instale Node.js 20 ou superior.
2. Abra esta pasta no VS Code.
3. No terminal, execute:

```bash
npm install
npm run dev
```

4. Acesse http://localhost:3000

## Personalizar

- Edite os textos e as opções em `app/page.tsx`.
- Ajuste cores, tamanhos e animações em `app/globals.css`.
- Os Genmojis personalizados estão em `public/genmoji/`.
- Para publicar, envie o projeto ao GitHub e importe o repositório na Vercel.

## Comportamento

- O botão “não” muda de lugar quando o cursor chega perto e também foge do toque no celular.
- “Sim” abre a tela de comemoração.
- A sequência seguinte permite escolher data, horário, comida e programa.
- A última tela mostra o resumo do date.

Antes de publicar, teste principalmente o botão fujão no celular e escolha se deseja deixar as opções de data e horário livres para ela.
